# iSONIC Website — Separated CSS & JavaScript

## Structure

isonic-website/
├── index.html
├── products.html
├── technology.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── assets/

## How to use

Open `index.html` in your browser.

All four pages use the same:
- `css/style.css`
- `js/app.js`

So when you change the design in `style.css`, it updates across the entire website.

When you change products, filtering, product details, navigation behavior, or form behavior, edit `js/app.js`.

## Important

Keep this folder structure unchanged so the relative links work correctly.
